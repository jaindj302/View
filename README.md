# View

## Skills

### `llm-council`

Runs a question, idea, or decision through a council of five AI advisors who
analyze it independently, peer-review each other anonymously, and then get
synthesized into a single verdict by a chairman.

Installed at `.claude/skills/llm-council/SKILL.md`. Trigger it in any Claude
Code session in this repo with phrases like "council this", "run the council
on ...", "pressure-test this", "stress-test this", or "war room this".

Adapted from [aiwithremy/claude-skills-llm-council](https://github.com/aiwithremy/claude-skills-llm-council)
by [Ole Lehmann](https://x.com/itsolelehmann), based on Andrej Karpathy's
[LLM Council](https://github.com/karpathy/llm-council) methodology.
